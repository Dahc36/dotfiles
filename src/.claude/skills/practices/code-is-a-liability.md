# Code is a liability

Code has to be maintained, which is costly.
Given similar solutions, the alternative that leads to less code should be preferred.

## Simplicity can justify more code

Code should be as easy to understand as possible.
Writing more lines of code can be justified for the sake of simplicity and clarity.

## Removing code is a big win

Removing lines to be maintained is always a win (unless it goes against simplicity).
